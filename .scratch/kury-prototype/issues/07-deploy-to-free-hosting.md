# 07: Deploy to free static hosting

**What to build:** The working prototype is available at a public URL so the keeper can open it on their phone anywhere and add it to the home screen. Use a free static host (Netlify, Vercel or GitHub Pages). Requires the keeper to log in to their own hosting account, hence a human ticket.

Note: data lives in localStorage per origin, so entries made against the local dev server will not appear in the hosted version.
